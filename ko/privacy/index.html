Kitchen Margin

개인정보 처리방침

Kitchen Margin은 Norman Zeng이 개발합니다. 이 방침은 Kitchen Margin 앱과 고객 지원 웹사이트에 적용됩니다.

방침 시행일: 2026년 9월 27일 · 한국어 번역: 2026년 10월 5일

핵심 내용

매장 기록과 문자 인식은 기기에서 처리·보관합니다. Kitchen Margin은 이러한 자료를 개발자 서버로 보내지 않으며 광고, 추적 또는 제3자 분석 SDK를 사용하지 않습니다. 구독 결제는 Apple에서 처리합니다. 파일을 내보내거나 공유할지는 사용자가 결정합니다.

설정의 사용 진단 정보 공유(Share usage diagnostics)는 선택 사항입니다. 기능 사용 횟수, 이벤트·설치 시각, 인식 처리 시간, 대략적인 자료 규모와 앱 버전을 포함하며 이름, 가격, 사진, 매장 자료나 직접 식별자는 포함하지 않습니다. 자동으로 전송하지 않습니다. 이메일에 첨부하면 문의자의 이메일 주소와 연결될 수 있습니다.

1. 앱에 보관하는 정보

앱은 사용자가 입력하거나 인식한 재료, 레시피, 가격, 수율, 알레르기 정보, 메모, 생산 계획, 판매·매입 기록, 측정한 폐기 기록, 원본 이미지, 인식된 글자, 이력과 설정을 기기에 보관합니다.

문자 인식은 Apple의 기기 내 기술을 이용합니다. 원본 사진과 인식된 글자를 Norman Zeng이나 개발자가 운영하는 인식 서비스에 업로드하지 않습니다. 개발자 계정으로 로그인할 필요가 없으며 개발자가 호스팅하는 매장 데이터베이스를 제공하지 않습니다.

2. 기기 권한

카메라 권한은 문서를 촬영하는 데 사용합니다. 사진 선택기는 사용자가 고른 이미지를 앱에 제공합니다. 앱은 해당 이미지에서 글자를 인식하고 기록의 원본으로 보관합니다. 권한은 기기의 설정에서 관리할 수 있습니다.

3. 구독과 Apple 서비스

Kitchen Margin은 Apple StoreKit으로 구독을 처리합니다. 구입, 결제 정보, 영수증과 거래 정보는 Apple의 약관 및 개인정보 처리방침에 따라 Apple에서 처리합니다. 앱은 Capture 접근 권한을 판단하기 위해 Apple에서 구독·거래 상태를 받습니다. 개발자는 사용자의 결제 카드 정보를 받지 않으며 구독 검증 서버를 운영하지 않습니다.

Apple은 사용자의 설정과 자체 방침에 따라 App Store 이용, 진단 정보, 기기 백업과 계정 정보를 별도로 처리할 수 있습니다. 앱은 개발자가 운영하는 분석 또는 충돌 보고 서비스를 사용하지 않습니다.

4. 내보내기, 공유와 기기 백업

사용자는 시스템 공유 기능으로 전체 백업, CSV와 기타 결과물을 내보낼 수 있습니다. 파일에는 민감한 매장 정보, 원본 사진과 사진에 포함된 개인정보가 들어 있을 수 있습니다. 사용자가 선택한 대상과 사람은 그 파일을 받아 각자의 방침에 따라 처리할 수 있습니다.

Apple 기기 백업에 앱 자료가 포함되는지는 사용자의 백업 설정에 따라 달라집니다. Kitchen Margin은 기기 간 매장 자료를 자동 동기화하거나 자체 클라우드 백업을 제공하지 않습니다. 구독을 구입해도 이 방식은 바뀌지 않습니다.

5. 보관과 삭제

앱은 사용자가 제거할 때까지 매장 자료를 기기에 보관합니다. 문서를 보관 처리하면 이력과 복원에 사용할 수 있으므로 영구 삭제가 아닙니다. 삭제하거나 교체한 일부 기록은 앱의 과거 스냅샷이나 복구용 사본에 남을 수 있습니다.

앱을 삭제하면 기기의 로컬 앱 자료가 삭제됩니다. 다른 사본도 제거하려면 내보낸 파일, 공유된 사본과 백업을 저장한 위치에서 별도로 삭제해야 하며 필요한 경우 Apple 백업도 관리해야 합니다. 개발자는 사용자의 기기나 선택한 저장 위치에 있는 사본에 접근하거나 삭제할 수 없습니다.

앱을 삭제하는 것만으로 구독이 취소되지는 않습니다. Apple 구독 설정에서 관리하거나 취소하세요.

6. 고객 지원과 웹사이트

이 정적 웹사이트는 GitHub Pages에서 호스팅합니다. 개발자가 추가한 분석, 광고, 추적 스크립트 또는 쿠키는 없습니다. GitHub는 서비스 제공과 보안을 위해 IP 주소 등 기술적인 요청 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보 처리방침을 확인하세요.

kitchenmargin.support@proton.me로 문의하면 개발자는 답변을 위해 이메일 주소와 메시지 내용을 받습니다. 사용 진단 정보 공유 파일에는 기능 사용 횟수, 이벤트·설치 시각, 인식 처리 시간, 마지막 인식 이후의 시간, 대략적인 자료 규모와 앱 버전이 포함됩니다. 이름, 가격, 사진, 매장 자료나 직접 식별자는 포함하지 않지만 이메일로 보내면 문의자의 이메일 주소와 연결되므로 그 상황에서 익명 자료는 아닙니다. 자동으로 전송하지 않습니다.

지원 이메일은 Proton 개인정보 처리방침에 따라 Proton Mail에서 처리합니다. 문의 해결과 후속 지원에 필요한 동안 연락 내용을 보관하며 같은 이메일 주소로 삭제를 요청할 수 있습니다. 민감한 기록을 보내지 말고 문제 설명에 필요하지 않은 정보는 가려 주세요.

GitHub 이슈로 문의하면 GitHub 사용자 이름과 게시한 모든 내용이 개발자와 일반에 공개됩니다. 개발자는 문의를 이해하고 답변하는 데 해당 정보를 사용합니다. 실제 납품서, 영수증, 매출 보고서, 백업, 비공개 매장 자료, 개인정보나 결제 정보를 게시하지 마세요. 가상 예시를 사용하세요.

공개 지원 글은 지원 기록으로 남을 수 있습니다. GitHub가 허용하는 범위에서 자신의 글을 수정하거나, 민감한 내용을 다시 게시하지 않고 같은 지원 경로로 삭제를 요청할 수 있습니다. GitHub의 보관, 계정 정보와 플랫폼 사본은 GitHub 방침을 따릅니다.

7. 방침 변경과 연락처

앱의 정보 처리 방식이 바뀌면 이 페이지를 갱신하고 시행일을 표시합니다. 이 방침에 관한 질문은 kitchenmargin.support@proton.me로 보내 주세요. 질문에 필요하지 않은 비공개 기록을 포함하지 마세요.

앱 이용에는 Apple 표준 최종 사용자 사용권 계약이 적용됩니다.
