隱私權政策

Kitchen Margin 由 Norman Zeng 開發。本政策適用於 Kitchen Margin App 與支援網站。

更新日期：2026 年 10 月 13 日

重點說明

廚房紀錄儲存在你的裝置，文字辨識也在裝置上處理。Kitchen Margin 不會將這些內容傳送至開發者伺服器，也不使用廣告、追蹤或第三方分析 SDK。訂閱付款由 Apple 處理。是否匯出或分享資料，由你決定。

設定中的「分享使用診斷」是選用功能，資料不會自動傳送。它不含名稱、價格、照片或廚房內容，但若以電子郵件寄送，報告會與你的電子郵件地址連結。

1. App 保留的資料

App 在裝置上保留你輸入或辨識的原料、配方、價格、可用率與產出率、過敏原資料、備註、製作計畫、銷售與進貨紀錄、實測損耗、來源圖片、辨識文字、歷史及設定。設定可包含你選擇的幣別、營業所在地、稅額處理與匯入欄位偏好。

文字辨識使用 Apple 的裝置內技術，不會將來源照片或辨識文字上傳給 Norman Zeng 或開發者經營的辨識服務。使用 App 不需要開發者帳號，開發者也不提供雲端廚房資料庫。

2. 裝置權限

相機權限用於拍攝文件。系統照片選擇器只將你選取的圖片提供給 App。App 會辨識圖片文字並保留作為紀錄來源。你可在裝置設定管理權限。

選用：匯入配方與本機表格

你可以從貼上文字、截圖或配方網頁連結匯入配方。選擇載入配方連結時，App 會直接向該網站發送 HTTPS 請求，包含允許的重新導向。網站可能依自身隱私權政策收到 IP 位址與請求頁面等一般網路資料。App 不會自動載入配方網頁，也不會把你的廚房紀錄傳送至該網站。

配方解析與截圖辨識均在裝置上進行。匯入功能不傳送或儲存網站 Cookie、不使用瀏覽器登入資料、不執行網頁指令碼，也不載入內嵌圖片等其他網頁資源。網頁或匯入的配方不會上傳給開發者。

繼續檢查配方時，原始貼上文字或下載的 HTML、可用的網頁連結，以及配方文字會隨來源紀錄保留在裝置上。CSV、TSV 與貼上表格也在裝置內處理；確認匯入的原料資料、來源標籤與列號會保留在紀錄中。你選擇的來源與欄位偏好可儲存於裝置，協助下次匯入。這些資料適用下方的備份、保留與刪除說明。

測試版選用：Google 試算表匯入

Google 試算表直接登入目前為核准測試帳號使用的預覽功能，不在公開 App Store 版本提供。若使用支援此功能的測試版，登入會在 Google 的系統認證畫面進行。Google 要求唯讀存取帳號內所有 Google 試算表；Kitchen Margin 只讀取你輸入連結的文件與選取的工作表，不列出 Drive 檔案、不修改試算表，也不在背景同步。

App 向 Google 傳送登入請求及讀取所選試算表所需的文件識別資訊。Google 依其隱私權政策處理請求。App 僅在使用匯入畫面期間，將短期存取權杖保留於記憶體，不儲存更新權杖，也不將權杖或試算表內容傳送給開發者。中斷 Google 連線會清除 App 內的存取權杖，你也可在 Google 帳號設定撤銷授權。

只有經你檢查並匯入的原料進貨資料會存入廚房紀錄。價格會作為目前原料價格，不會建立歷史進貨單或支出合計。App 會在裝置記住與文件、工作表及欄名雜湊值連結的欄位編號，減少重複操作；此偏好不保存工作表原始內容。

Kitchen Margin 使用及移轉 Google API 資料時遵守包含有限使用規定的 Google API 服務使用者資料政策。Google 資料只用於你要求的匯入功能，不用於廣告、出售或訓練 AI 模型。

3. 訂閱與 Apple 服務

Kitchen Margin 使用 Apple StoreKit 處理訂閱。購買、付款資料、收據與交易資訊由 Apple 依其條款及隱私權政策處理。App 從 Apple 取得訂閱與交易狀態，以判斷 Capture 使用權。開發者不取得你的付款卡資料，也不經營訂閱驗證伺服器。

Apple 可能依你的設定與自身政策，另外處理 App Store 使用、診斷、裝置備份與帳號資料。App 不使用開發者經營的分析或當機回報服務。

4. 匯出、分享與裝置備份

你可透過系統分享功能匯出完整備份、CSV 及其他結果。檔案可能含敏感店家資訊、來源照片及照片中的個人資料。你選擇的接收人或服務會取得檔案，並依其自身政策處理。

Apple 裝置備份是否包含 App 資料，取決於你的備份設定。Kitchen Margin 不會自動跨裝置同步廚房資料，也不提供開發者代管的雲端備份；購買訂閱不會改變此方式。

5. 資料保留與刪除

廚房資料會保留在裝置，直到你移除。將文件封存或從使用中清單移除，不等於永久刪除，因為來源與歷史仍供復原。某些已刪除或替換紀錄也可能保留在歷史快照或復原副本中。

刪除 App 會移除裝置上的本機 App 資料。若要移除其他副本，需在各儲存位置另外刪除匯出檔、分享副本及備份，必要時也管理 Apple 備份。開發者無法存取或刪除你裝置或所選儲存位置中的副本。

刪除 App 不會取消訂閱。請至 Apple 訂閱設定管理或取消。

6. 支援與網站

此靜態網站由 GitHub Pages 託管。開發者未加入分析、廣告、追蹤指令碼或 Cookie。GitHub 可能為提供服務與安全而處理 IP 位址等技術請求資訊，詳見 GitHub 隱私權聲明。

寄信至 kitchenmargin.support@proton.me 時，開發者會取得你的電子郵件地址與訊息內容，以理解並回覆問題。選用的使用診斷檔包含功能次數、事件與安裝時間、辨識耗時、距上次辨識的時間、概略資料規模及 App 版本，不含名稱、價格、照片、廚房內容或直接識別資訊。若透過電子郵件寄送，會與你的信箱連結，因此在該情況下並非匿名。診斷不會自動傳送。

支援電子郵件由 Proton Mail 依其隱私權政策處理。聯絡內容會保留至解決問題與後續支援所需的期間；可向同一支援信箱要求刪除。請勿傳送與問題無關的敏感資料，分享必要畫面前請先遮蔽。

透過 GitHub issue 提問時，你的 GitHub 使用者名稱與貼出的所有內容都會向開發者及公眾顯示。開發者使用它們理解並回覆問題。請勿公開真實進貨單、收據、銷售報表、備份、非公開店家資訊、個人或付款資料；請使用虛構範例。

公開支援貼文可能保留為支援紀錄。你可在 GitHub 允許的範圍內編輯自己的貼文，或透過相同管道要求刪除，而不再次公開敏感內容。GitHub 的保留方式、帳號資訊與平台副本依其政策處理。

7. 更新與聯絡方式

資料處理方式改變時，本頁會更新並標示日期。若對本政策有疑問，請聯絡 kitchenmargin.support@proton.me，不必附上無關的非公開紀錄。
